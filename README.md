# Repositório de Atividades Acadêmicas - Sistemas de Informação IFMA

Este repositório serve como um portfólio acadêmico, reunindo atividades e projetos desenvolvidos ao longo do curso de Sistemas de Informação no Instituto Federal do Maranhão (IFMA). O objetivo é apresentar a evolução dos meus estudos e a aplicação prática de conceitos de programação e tecnologia.

---

### Organização do Repositório

O conteúdo está dividido por semestre, com foco nas principais disciplinas e nos conhecimentos adquiridos.

#### **1º Semestre: Fundamentos de Programação**
* **Tecnologia:** Linguagem C
* **Destaque:** Projetos focados em aprimorar a lógica de programação.

#### **2º Semestre**
* **Estrutura de Dados I**
    * **Tecnologia:** Linguagem C
    * **Destaque:** Implementação de estruturas de dados essenciais, como Árvores, Filas e Listas, para aprimorar a manipulação e a organização de dados.
* **Programação Orientada a Objetos (POO)**
    * **Tecnologia:** Linguagem Java
    * **Destaque:** Aplicação dos conceitos fundamentais de POO, como classes, objetos, herança e polimorfismo.

#### **3º Semestre**
* **Laboratório de Banco de Dados**
    * **Tecnologias:** JPA, SQL, Jasper Studio
    * **Destaque:** Aprofundamento em modelagem de dados, persistência de objetos e a geração de relatórios dinâmicos.
* **WEB - I**
    * **Tecnologias:** HTML, CSS, JavaScript
    * **Destaque:** Atividades e projetos que exploram as principais ferramentas e conceitos do desenvolvimento web.

Sinta-se à vontade para explorar os projetos e o código-fonte de cada disciplina.

🚀 Como Clonar o Repositório
Para clonar este repositório em sua máquina local, utilize o seguinte comando no terminal:
git clone https://github.com/Alan-mondego/si-ifma.git
